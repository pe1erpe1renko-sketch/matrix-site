# MATRIX

Сайт-калькулятор матрицы судьбы по дате рождения.

## Запуск

```bash
npm install
npm run dev      # локальный просмотр
npm run build    # сборка
npm test         # тесты движка расчёта
```

## Структура

```
src/
  lib/          движок расчёта и контентный слой — не переписывать
    urlDate.js  перевод даты между адресом (13-07-1998) и движком (1998-07-13)
  theme/        дизайн-токены, общий словарь стилей, глобальный CSS
  components/   макет, меню, фон, курсор, заглушка страницы
  pages/        страницы сайта
  routes.js     карта сайта: меню, вкладки формы и маршруты из одного списка
  App.jsx       маршрутизация
CLAUDE.md       полное описание проекта: методика, тарифы, план работ
```

Перед изменениями прочитайте `CLAUDE.md`.

## Адреса

| Адрес | Что показывает |
|---|---|
| `/` | главная, вкладка «Матрица» |
| `/matrica`, `/finansy`, `/sovmestimost`, `/biznes`, `/detskaya`, `/prognoz` | главная с выбранной вкладкой формы |
| `/matrica/13-07-1998` | разбор по дате |
| `/sovmestimost/13-07-1998/09-04-1992` | разбор по двум датам |
| `/chat`, `/tarify`, `/profil` | кабинет |

## Требование к хостингу

Страницы вида `/matrica/13-07-1998` должны открываться **по прямой ссылке** —
на этом держится поисковый трафик и пересылка ссылок. Файлов с такими именами
на диске нет, страницу собирает приложение в браузере, поэтому хостинг должен
отдавать `index.html` на любой неизвестный адрес вместо ошибки 404.

Для Netlify и Cloudflare Pages правило уже лежит в `public/_redirects`.
На других хостингах то же самое настраивается в их панели:
- Vercel — `rewrites` на `/index.html`;
- nginx — `try_files $uri /index.html;`;
- GitHub Pages — копия `index.html` под именем `404.html`.

Проверить просто: откройте `/matrica/13-07-1998` в новой вкладке.
Если видите разбор — настроено верно, если 404 — нет.
